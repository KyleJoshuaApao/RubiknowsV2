## Agent skills

### Issue tracker

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

The default triage labels (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix) are used. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (one `CONTEXT.md` and `docs/adr/` at the root). See `docs/agents/domain.md`.
